# B3 — Tables `public` encore ouvertes à `anon`, hors lot 5 (inventaire 2026-09-14)

Lecture seule : base de production en SELECT uniquement, code lu, aucune écriture en base, aucun git.
Inventaire pour décision de Roméo, **sans recommandation d'application**.
Complète `docs/scratchpad/audit-2026-09-14-BO-SEC-005-tables-hors-lot.md`, qui ne couvrait que les 40 tables sans policy.

## 1. Périmètre et méthode

- Objets : tables `relkind IN ('r','p')` du schéma `public` où `has_table_privilege('anon', oid, …)` est vrai pour
  SELECT, INSERT, UPDATE ou DELETE, **hors les 56 tables du lot 5**. Résultat : **77 tables**, toutes avec RLS
  activée (aucune avec FORCE RLS), et **toutes avec les 4 droits S/I/U/D pour `anon`**.
- Policies : `pg_policies` dont `roles` contient `anon` ou `public`. Rappel : une policy `TO public` s'applique aussi à
  `anon`. La colonne « remarque » dit si la policy produit réellement quelque chose pour un visiteur non connecté
  (beaucoup exigent `auth.uid()` et ne donnent rien à `anon`).
- Appels anon : `extensions.pg_stat_statements` avec `userid = oid(anon)`. Une requête est comptée pour une table si son
  texte contient le nom de la table **en mot entier** (`~* '(^|[^a-z0-9_])<table>([^a-z0-9_]|$)'`), plus précis que les
  `ILIKE` demandés (évite `products` ⊂ `products_x`). Les jointures PostgREST comptent donc pour chaque table jointe.
  - Fenêtre : depuis le **2025-09-05** ; `dealloc = 133` (des requêtes rares ont pu être évincées).
  - Une requête **refusée** (droit ou RLS en INSERT) n'est pas comptée.
  - La colonne `rows` vaut toujours `calls` (PostgREST renvoie 1 ligne d'enveloppe) : **elle ne dit pas combien de
    lignes métier ont été servies**.
- Code : `/usr/bin/grep -rnE` sur `apps/site-internet/src` et `apps/linkme/src` (hors tests et types générés), motifs
  `.from('<table>')` et jointures `<table>(` / `alias:<table>(` / `<table>!inner(`. Type de connexion lu dans le
  fichier : **service** = clé service_role (ne passe pas par `anon`) ; **cookie** = client serveur avec session du
  visiteur ; **navigateur** = client navigateur (anon si pas de session) ; **clé anon** = clé anon sans session
  (toujours `anon`).
- Pages publiques LinkMe (middleware `PUBLIC_ROUTES`) : `/`, `/login`, pages vitrine, `/s/*`, `/delivery-info/*`,
  `/complete-info/*`, API `complete-info`, `auth`, `health`, `globe-items`, `contact`, `page-config`,
  `emails/order-confirmation`, `emails/step4-confirmed`, `emails/notify-enseigne-order`.
  `/(main)/[affiliateSlug]` (qui importe `use-linkme-public.ts`) est **connecté**. Site : `/compte` et `/ambassadeur`
  exigent une session.

## Annexe — requêtes SQL (lecture seule)

### A1. Tables ouvertes à anon hors lot 5, RLS, policies anon/public

```sql
WITH lot5(t) AS (VALUES ('ai_generation_logs') /* … 56 tables du lot 5 … */)
SELECT c.relname, c.relrowsecurity, c.relforcerowsecurity,
  concat_ws(',', CASE WHEN has_table_privilege('anon', c.oid, 'SELECT') THEN 'S' END,
    CASE WHEN has_table_privilege('anon', c.oid, 'INSERT') THEN 'I' END,
    CASE WHEN has_table_privilege('anon', c.oid, 'UPDATE') THEN 'U' END,
    CASE WHEN has_table_privilege('anon', c.oid, 'DELETE') THEN 'D' END) AS anon_privs,
  (SELECT string_agg(p.policyname || ' [' || p.cmd || ' ' || array_to_string(p.roles, '/') || ']', ' || ')
     FROM pg_policies p WHERE p.schemaname='public' AND p.tablename=c.relname
      AND (p.roles && ARRAY['anon','public']::name[])) AS anon_public_policies
FROM pg_class c JOIN pg_namespace n ON n.oid=c.relnamespace
WHERE n.nspname='public' AND c.relkind IN ('r','p')
  AND (has_table_privilege('anon', c.oid, 'SELECT') OR has_table_privilege('anon', c.oid, 'INSERT')
    OR has_table_privilege('anon', c.oid, 'UPDATE') OR has_table_privilege('anon', c.oid, 'DELETE'))
  AND c.relname NOT IN (SELECT t FROM lot5)
ORDER BY c.relname;
```

### A2. Appels anon par table

```sql
WITH t(tbl) AS (VALUES ('addresses') /* … 77 tables … */),
s AS (SELECT query, calls FROM extensions.pg_stat_statements
      WHERE userid = (SELECT oid FROM pg_roles WHERE rolname='anon')),
m AS (SELECT t.tbl, s.query, s.calls FROM t JOIN s
      ON s.query ~* ('(^|[^a-z0-9_])' || t.tbl || '([^a-z0-9_]|$)'))
SELECT t.tbl, coalesce(sum(m.calls),0) AS anon_calls, count(m.query) AS nb_queries,
  (SELECT left(m2.query,150) FROM m m2 WHERE m2.tbl=t.tbl ORDER BY m2.calls DESC LIMIT 1) AS example
FROM t LEFT JOIN m ON m.tbl=t.tbl GROUP BY t.tbl ORDER BY t.tbl;
```
